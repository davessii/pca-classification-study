# Клиентские данные

Полный Customer_Data.csv не публикуется. Для исходного notebook требуется совместимая копия этого набора рядом с notebook. Нужны поля Customer_Status, CustCreationDate, Net_ Purchase(IRR), Avg_Invoice_Row_No, Waste_Rate, Rejected_Rate, Avg_Purchase_In_Month, Date_Of_Last_ Purchase. Идентификаторы исключаются кодом предобработки.

Для знакомства с проектом используйте demo.py: он сам создаёт искусственные признаки и метки без клиентских записей.
